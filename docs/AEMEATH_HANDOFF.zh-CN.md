# Aemeath 助手 · 自动战斗与队伍工坊交接

2026 年 11 月 21 日。此分支以 OK-WW `v3.8.9` 的 `46a334c5` 为基线。

## 改动原因与内容

原先切人后固定补一次普攻。队伍界面延迟时会重复发送切人键和鼠标点击。部分固定轴的技能等待缺少超时，技能条件一直未满足时会持续补按。现在以队伍界面确认切人，重试最多三次，等待窗口结束后交由任务的战斗退出处理。

| 自动战斗输入 | 每次抽取的区间 |
| --- | --- |
| 不同操作最短间隔 | 80–90 ms |
| 同一键或鼠标按钮最短间隔 | 150–170 ms |
| 普通短按的按住时长 | 35–45 ms |
| 切人未确认时的重试等待 | 420–480 ms |

输入节奏由 `src/combat/InputPacing.py` 管理。技能冷却、动画、显式长按和超时仍遵循对应的战斗逻辑。等待队伍界面恢复或切人冷却结束期间暂停补按。动作状态、捕获耗时和调度都可能增加实际间隔。

工坊使用 XJTU-WW `v1.3.0` 的固定快照，共 54 支队伍、82 份配置。安装时逐个校验 SHA-256，并在本机生成 20 份适配过的归档。心莉锁等队伍的短窗口补 E 次数受限，丽贝卡机枪段减少普攻重试，爱弥斯／琳奈／莫宁的 25 秒轴遇到技能等待超时会尝试切走。直接调用系统输入的归档也接入共用节奏。

## 绯洛穗内置优化 1.0.0

## 在另一台 Windows 电脑安装

1. 取出 fork 中的 `feat/aemeath-combat-pacing` 分支。完全退出 OK-WW 或 Aemeath 助手。先确认实际使用的 `working` 目录和 `v3.8.9` 版本，并保留近期修改的队伍代码。
2. 在仓库根目录运行以下 PowerShell 命令。按安装位置修改 `$working`。Python 和 Git 供安装脚本使用。

   ```powershell
   $working = 'D:\OK-VV\ok-ww\data\apps\ok-ww\working'
   $python = Join-Path (Split-Path -Parent $working) 'python\python.exe'
   & $python .\tools\aemeath\install.py --working $working
   ```

   安装脚本会补入 `working\ok` 下的三个输入适配文件、工坊页、队伍载入代码和自动战斗代码，并输出备份位置。网络受限时可以用 `--bundle-source` 指定从 XJTU-WW `v1.3.0` 取得的原始 `workshop_bundle`。`--app-only` 仅应用程序改动。安装检测到核心源文件有额外编辑时会报出路径，先合并这些文件并保留双方改动。
3. 如需桌面上的 `Aemeath 助手` 快捷方式和 `Aemeath.exe` 进程名，在同一目录执行以下命令。

   ```powershell
   .\tools\aemeath\New-AemeathShortcut.ps1 -Working $working
   ```

4. 在工坊选择队伍后可切换为导入代码。新建的预导入队伍初始使用内置代码。已有同名队伍仅在角色文件与已知快照原样匹配时应用该角色的节奏补丁。这有助于保留本地编辑和当前代码模式。
5. 如需复测这次的「绯洛穗·内置优化」，在队伍工坊用「导入队伍代码」选择仓库 `tools/aemeath` 中的新版 ZIP。基础安装脚本会恢复社区快照，这份本地优化包需单独导入。导入前可导出该队当前配置用于回退。确认队伍信息显示「绯洛穗·内置优化」且模式为导入代码，结束当前自动战斗后重新进入。做对照时在该队切换为内置代码，测试后再切回导入代码。

## 验证与注意事项

- 已在本机验证桌面入口启动、工坊可读取 82 份归档，并用离线模拟验证间隔范围、切人确认及超时、技能不亮时的退出行为。在独立安装样本上复验了 54 支队伍、82 份归档、20 份适配结果和重复安装。固定轴在不同帧率、设备和游戏场景下的实际衔接待实战验证。
- 同一分支里的 `tools/aemeath/workshop-snapshot.json` 记录原始社区资源的提交和校验值。安装时会保留原始作者和来源说明。队伍 ZIP 内含可执行 Python，导入前可在工坊预览。
- 框架更新可能替换 `working` 以及输入适配文件。更新后需重新核对 `src/combat/InputPacing.py` 和对应三个输入后端的调用关系，并检查工坊的左侧入口和队伍模式。
- 安装回退时退出助手，将 `working` 同级 `aemeath-backup-*` 中的文件按相对路径恢复，按其中 `added-files.json` 移除该次新增且之后未编辑的文件。保留近期修改的队伍配置副本。
- 拉海洛方块的旧交接记录中，上游已通过 PR #1866 合入奖章棋盘截图和托盘识别测试。后续若继续做棋盘续跑，已通关的 4500 分棋盘要以「挑战成功」和返回关卡列表为复测重点，同时复测首次通关仍可停在「获得」弹窗。
- 荣耀之丘由另一台电脑继续自动化。完成后从那台电脑提交对应改动。合并到同一基线时重点检查 `config.py` 的 `onetime_tasks` 仍注册 `GloryHillTask`，以及桌面助手依然加载本分支的工坊和输入节奏。安装脚本只替换 `config.py` 中的窗口标题字段。
